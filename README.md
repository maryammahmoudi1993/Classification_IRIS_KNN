# Classification_IRIS_KNN

**This repository now points to its successor: [KNN_IRIS_classification](https://github.com/maryammahmoudi1993/KNN_IRIS_classification).**

That repository is a step-by-step tutorial on classifying Iris flowers with K-nearest neighbours. It starts from the original 2022 script (kept untouched in its `legacy/` folder) and explains each idea in small steps, with figures and tested code:

| Notebook | Question it answers |
|---|---|
| [01 · The problem and the KNN idea](https://github.com/maryammahmoudi1993/KNN_IRIS_classification/blob/main/notebooks/01_the_problem_and_the_knn_idea.ipynb) | What is KNN, and why can one accuracy number mislead? |
| [02 · Distance, k and cross-validation](https://github.com/maryammahmoudi1993/KNN_IRIS_classification/blob/main/notebooks/02_distance_k_and_cross_validation.ipynb) | Which `k`? Does scale matter? How do we measure fairly? |
| [03 · Is KNN the right model?](https://github.com/maryammahmoudi1993/KNN_IRIS_classification/blob/main/notebooks/03_is_knn_the_right_model.ipynb) | How does KNN compare with other classifiers? |
| [04 · Explaining KNN with SHAP and LIME](https://github.com/maryammahmoudi1993/KNN_IRIS_classification/blob/main/notebooks/04_explaining_knn_with_shap_and_lime.ipynb) | Why did it choose that species? |

## Why this repository still exists

It is kept as a pointer so that older links still lead to the project, and so that nothing is deleted. It has no code of its own: when it was prepared for this change it contained no commits, so there were no original files to move into a `legacy/` folder.
